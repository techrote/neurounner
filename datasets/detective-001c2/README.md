# DETECTIVE-001C2 pairwise repair corpus

Two 40-pair shards, one per immutable C1 witness adapter. Each has 32 new proposition-repair pairs (lie, withholding, correction, speculation) and 8 exact C1 temperament anchors. New repair prompts are from case families disjoint from C1 training/final and are prospectively validated by the frozen C2-A proposition scorer: chosen must pass, rejected must fail. C1 final prompts are used only as a collision index and are never training material. No learner-final C2 suite exists in this dataset.
