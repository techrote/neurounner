# C²KV: Compressed and Composable KV Cache Reuse for Efficient LLM Inference

**Primary reference:** https://arxiv.org/abs/2607.17715

## Brief summary report
A trained sidecar extracts compact position-agnostic cached chunks, jointly optimised with inference-time concatenation for non-prefix cache reuse.

## MEMPLANT relevance
Especially useful for a memory-store design with compressed independently reusable shards.

## Scope and limitations
Not an architecture-neutral cross-model representation; reported efficiency is specific to benchmark settings.

## Recommended controlled experiment
Evaluate compression jointly trained for composition versus compression alone.
