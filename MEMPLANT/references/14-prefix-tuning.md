# Prefix-Tuning: Optimizing Continuous Prompts for Generation

**Primary reference:** https://aclanthology.org/2021.acl-long.353/

## Brief summary report
Freezes pretrained weights and optimises small continuous virtual prefixes to condition generation.

## MEMPLANT relevance
Foundational deep-prefix mechanism for injecting temporary model-native memory positions.

## Scope and limitations
Classical learned task prefixes are not dynamic transplants compiled from arbitrary live conversation context.

## Recommended controlled experiment
Compare a static learned prefix with a generated query-aware deep prefix.
