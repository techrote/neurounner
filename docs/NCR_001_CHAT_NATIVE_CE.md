## New bounded synthetic/native protocol

`scripts/ncr_001_sprocket_chat_native_ce.py` encodes two *invented synthetic* source-formatted prompts, one user-only and one alternating user→assistant→user context. It completes each with a distinct plain assistant text and explicitly appends the genuine role END ID **5** as a supervised next-token target; no literal EOS text, tool markers, held-out samples, or learnt model outputs are reused. The earlier context (including previous assistant turns) is intentionally **context-only**; the final assistant body + END are the **only supervised** positions. Both rows are packed into one left-padded batch with **explicit attention** and labels `-100` for host/context/artificial pads. Because source END ID5 is also the synthetic pad ID5, any naive `input_ids != 5` mask must fail the sentinel while genuine attended END markers remain visible.

On exactly the verified original **Chat** model, compare native HF `forward(labels=..., use_cache=False)` CE to independent mean per-supervised-target `logsumexp - selected_logit` using logits at j−1 and target at j, with a separately scoped 1e−5 absolute **float32 loss-reduction diagnostic** tolerance (no change to protocol full-vs-cache `5e-4` tolerance). Compare same model logits and loss under zero-initialized and disabled **NCA (658,904 adapter parameters)** and matched **gated MLP (658,432)** wrappers, explicitly check frozen backbone complete tensor fingerprint before/after, no base gradients and **zero optimizer steps**. The source is pinned to original protocol Git blob `14ce5fbaa38f8806c8c8738f19c01b91385eebaf`, source-pins blob `59fff1aed872b5563aa6898171983973e0cdb02c`, and full SHA-verified Chat checkpoint/tokenizer/config/card before switching HF offline.

Eleven toy-unit adversarial and positive source tests reject Chat role-control injection, wrong shared END/pad ID, bad assistant supervision counts, context labels, padded attention, missing causal predecessor, invalid target IDs, nonfinite CE and off-by-one logits. The fake test tokenizer intentionally **is not the frozen real tokenizer**; the original-model Actions step independently executes the actual pinned tokenizer and weights.
