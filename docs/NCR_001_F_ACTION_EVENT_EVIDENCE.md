The unrelated green `VILLAGE-001 population preflight` PR workflow is never accepted as NCR provenance.

## Independent, fail-closed procedure

[Auditor](../scripts/ncr_001f_action_event_audit.py) uses read-only GitHub REST to fetch the **immutable exact original Git commit** (SHA, tree and first-parent IDs pinned separately for #99 and #198), the current PR's *mutable* readiness/merge/head state, a **complete per-original-head all-event workflow inventory** (`head_sha`, 100 per page; rejects incomplete pagination and malformed/missing/duplicate originals) and exact original run/job records. It verifies original branch, repository, Git tree/ancestry, workflow path, event, status, attempt and job ID/name/head. The two original archived domain **push** jobs remain distinct from the unrelated VILLAGE **PR** jobs. No later workflow or altered PR state can promote scientific qualifications.

**G8 lifecycle correction:** the prior source-only auditor required #99/#198 to remain *open drafts* and their live inventory to contain **exactly** two historical runs. That was a valid instantaneous G1 frozen-draft sentinel but not durable evidence custody: an owner's readiness/merge, historical-head rebase/second-parent composition or subsequent independent workflow could make the previous source-only green archive checker red despite intact original 2026-10-29 source proofs. The current audit **keeps the original two run IDs/sha/tree/job provenance exactly pinned** while separately reporting `current_pr_head`, `current_pr_state`, `current_pr_merged` and `additional_runs_unreviewed`. Any later runs are never substituted for original jobs or treated as verified NCR PR-event checks. When extras appear, `domain_pull_request_check_present=null` denotes **not assessed** (instead of falsely asserting false), and `domain_pull_request_check_verified=false` always denotes no qualified domain-PR check in this original historical proof. Malformed original IDs, changed source Git tree/ancestry, missing original runs, source/job drift, incomplete pagination and foreign repo are still hard failures. Counts greater than 100 fail pending deliberate paginated qualification, rather than silently reading a partial snapshot.

[Adversarial offline tests](../tests/test_ncr_001f_action_event_audit.py) reject original-source Git object/tree/parent swaps, wrong original run/job ID/branch/event/workflow, incomplete or duplicated inventory, foreign repository, failure/skipped original jobs, altered attempts and false domain attribution. Positive cases prove a PR becoming ready, merged/closed or having a recomposed head **does not alter past original Git/Actions facts**; an added green or failed run remains `additional_runs_unreviewed`, excluded from the historic evidence. [Read-only literal-head workflow](../.github/workflows/ncr-001f-action-event-audit.yml) runs all cases under normal and optimized Python, verifies immutable protocol and source-pin Git blobs, and performs fresh original evidence readback. Transient Actions artifacts do not supersede original Git-custodied evidence.

## Limits

This is a historical **event-scope and provenance classifier** for two immutable original Git/Actions heads only, not a classifier of every later run attached to those commits or a present-day PR integration verdict. A successful **push read-only archival check is not a PR-domain check**, a fresh model-host execution, a new original-model no-op/causal acceptance, training-compute measurement, or an independent human scientific review. Preserve original physical/ZIP/log custody and all negative evidence in existing historical branches; no original bytes are rewritten.

Explicit locked conclusions: `train_authorized=false`, `full_72_conformance_pass=false`, `actual_compute_budget_qualified=false`, `model_executed=false`, `optimizer_steps=0`, `heldouts_opened=false`. No protocol, source pins, fixture, matched model parameterization or main merge is changed.
