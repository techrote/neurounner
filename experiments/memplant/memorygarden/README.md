# MEMPLANT — Living Memory Garden and Native-State Experiments

**Research-only. Draft/HOLD.** Uses the existing neurounner subjects and research chain. Parent: [DREAMGRAFT-002 PR #233](https://github.com/techrote/neurounner/pull/233). No merges or production modifications.

## Three independent experiments

| Experiment | Real subjects | Test |
| --- | --- | --- |
| **COUNTERFACTUAL-ALLELE-001** | Frozen Qwen2.5-0.5B source attention states | Learn average additive heat/vibration feature deltas only on the existing DG002 training worlds; apply to separately pre-encoded held-out worlds. Compare true re-encoding, norm-matched random edit, and wrong-axis edit. |
| **NATIVE-KV-CUSTODY-001** | Qwen2.5-0.5B loaded as two distinct model objects at the same exact checkpoint | Copy actual native K/V cache from source A, unload A, resume generation in fresh recipient B without giving B the source tokens. Compare its logits with identical full-context prefill and with wrong-donor cache. |
| **LIVING-GARDEN-001** | Current pinned **Sprocket-500M** and **LFM2.5-1.2B-Instruct** GGUF models, with real Qwen V features | Generate mechanical inventions for worlds with unknown heat/vibration rules. Test no-memory, state-derived two-bit *text postcards*, counterfactual wrong postcards, and full source narrative. Grade device structure in an executable three-gate deterministic micro-simulation. |

**Strict method distinctions:** The allele acts on *pooled contextual features*, not native cache layers; the native K/V clone uses **identical checkpoint weights and architecture**, not cross-family translation; Sprocket and LFM receive **ordinary text postcards** made from donor-derived supervised ridge scores, not dense native model states. None of the three by itself proves cross-family live-memory transplantation.

All experiments use the immutable genuine Qwen source archive from [DREAMGRAFT-002 Actions run #43736088404](https://github.com/techrote/neurounner/actions/runs/43736088404), pinned model revisions and SHA-256 evidence. No weights or confidential conversations are committed.

## What the garden tests

A machine proposal must choose a frame that survives warming, a collector that captures floating or sinking dust, and a correct operational sequence. All three decisions must match the world; passing the deterministic simulator means 16 simulated successful cycles. The four source worlds contain all combinations of heat hardens/softens and dust floats/sinks.

An invention that works in one world may fail in the counterfactual world. The machine and its explanation are generated by each existing neurounner subject. Original prose, invalid JSON and unsuccessful devices are all retained, not polished away.

This is a deliberately tiny toy mechanics evaluator. It provides *functional feedback*, not accurate materials science.

## Interpretation

- G2 source features and earlier sealed world families have been inspected in previous turns. The allele tests are **exploratory**, not a newly sealed population-level confirmation.
- The two-bit textual postcard is a consumer baseline, not numeric transplantation into Sprocket or LFM.
- A same-checkpoint native cache clone qualifies transport/custody, not conversion between heterogeneous LLMs.
- The prior [DG003 PR #234](https://github.com/techrote/neurounner/pull/234) failed to finish its 24-case CPU comparisons before timeout; those failures were not negative evidence about reasoning quality. This branch does not silently declare the DG003 result.
- The running models and raw evidence are isolated in [the dedicated Actions workflow](../../../.github/workflows/memplant-living-garden.yml).
- All artifacts are temporary 30-day Actions evidence; long-lived storage requires a separate owner decision.

## Reproduction

With the prior source ZIP extracted into runtime/memplant/garden/source, a compatible Python environment, and the repository root as working directory:

    python3 -m unittest discover -s tests -p test_memplant_garden.py -v
    python3 -m experiments.memplant.memorygarden.allele --source runtime/memplant/garden/source --out runtime/memplant/garden/allele.json
    bash scripts/bootstrap.sh sprocket
    python3 -m experiments.memplant.memorygarden.subjects --subject sprocket --source runtime/memplant/garden/source --out runtime/memplant/garden/sprocket.json

**No merges, no Ready promotion, no alteration of production runners.** Outcomes are judged by real source-specific effects and functioning inventions, not simply a successful CI exit code.
