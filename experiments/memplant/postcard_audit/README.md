# DREAMGRAFT G1C — frozen transferred signal confirmation

A **new confirmatory experiment** following the promising but tiny G1B result. No training is performed here: the G1B ridge readout and both B-native continuous prefixes are loaded byte-for-byte from [G1B run #43693630530](https://github.com/techrote/neurounner/actions/runs/43693630530), artifact 14154107117. The adapter checksum is verified to prevent silent re-fitting or replacement.

**Unseen bank:** eight synthetic world families, each with a hardens/softens counterfactual twin, using several previously unused narrative structures and materials. Qwen2.5-0.5B is prefixed once per source to obtain genuine layerwise V state; frozen SmolLM2-1.7B receives **only** numerical donor-derived prefixes under the fixed task prompt.

**Core controls:** continuous blend from true donor; continuous blend from the opposite-rule twin; blend from unrelated opposite-rule world; zero; norm-matched random; direct hard gate; 50/50 fixed blend; and explicitly identified native full-source text. Test both answer-option orders, answer original source **and swapped donor** truth, and count actual recipient prediction reversals. A few raw creative attempts are archived but never counted as factual evidence.

**Scope:** supervised **scalar feature → B-native pseudo-embedding** channel, not transferable native K/V, original user conversation compression, reusable portable memory, generational inference, or causal world surgery. Eight world families remain a small sample. All other MEMPLANT milestones and all PR merges remain HOLD.

**Implementation:** [workflow](../../../.github/workflows/memplant-g1c-confirm.yml) pins both model revisions, the prior artifact ID/hash and bounded Ubuntu CPU inference; no source or adapter training in B audit. Original synthetic text, all raw scores and exceptions are preserved as GitHub Actions artifacts.
