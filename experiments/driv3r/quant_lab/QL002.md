# QL-002 — BRANCH/RETRACE extreme-quant repair (synthetic game worms)

**Draft/HOLD. Research-only.** This file extends [QL-001](README.md) without changing CyberSand game/native/Godot/workbench code or any provider. It tests whether the QL-001 trained policy's **zero BRANCH recall** was a data/objective problem, not a precision ceiling. These are tiny neural steering policies, **not** GGUF IQ1/IQ2/IQ3 SLM quantization, native W0 runs, or complete-scene artists.

## Reproducible bounded experiment

Run \`python experiments/driv3r/quant_lab/ql002_branch_retrace.py --self-test\`, then \`python experiments/driv3r/quant_lab/ql002_branch_retrace.py --out ql002-out --steps 350 --repair-steps 75\` with QL-001's exact pinned Python/Torch/NumPy/Pillow dependencies. A dedicated Actions workflow produces immutable optimizer-bearing checkpoints (ordinary vs class-balanced), Q2 STE-QAT repair checkpoint, nine packed variants, raw score/host choice receipts, 108 original synthetic PNGs and SHA-256 inventory. Source SHA is embedded. No external paid compute.

**Corrected teacher contract:** Every target is chosen from the actual host legal actions. It now intentionally produces RETRACE on local dead ends/short exploratory recoveries and BRANCH on legal, nontrivial multi-option states. Both train and held-out worlds contain all six actions. Timing/family-conditioned target choices derive exclusively from observable tick, family and local state—not hidden world seed. Random exploration never arbitrarily stops a curriculum episode, but STOP remains legal, trainable and **unsuppressed** in first-pass policy evaluation.

The ordinary and class-balanced models start from the same initialization and get the same count of optimizer updates (350); the balanced model samples observed legal examples inversely by class frequency. It is **not** a same-minibatch, same-gradient counterfactual. Independent held-out seeds are 9100–9131 (train 2100–2179); original galleries use held-out 9103/9111/9127 × Greebles/Pipework/Architecture. Model-free random/wall/fidget use the same obstacle seed and host RNG stream; diverging state trajectories do not provide exact same-state matched comparisons. The inference path reloads actual packed Q1/Q2/Q4/mixed/sparse/QAT weights but dequantizes them to FP32 CPU matmul; measured latency is **not** packed low-bit execution.

## Local provisional proof-run (not exact-HEAD GitHub Actions)

A local CPU dry run with these training/repair steps and seeds produced 4,352 held-out synthetic states: BRANCH 775, RETRACE 844, STOP 128, STRAIGHT 1,348, LEFT 591, RIGHT 666. Results below describe **unmasked** teacher-action recall with denominator given by this actual held-out histogram.

| Variant | Teacher accuracy | BRANCH recall (n=775) | RETRACE recall (n=844) | STOP recall (n=128) | 9-case mean cells |
| --- | ---: | ---: | ---: | ---: | ---: |
| Regular FP32 | 60.66% | 6.32% | 54.15% | 21.09% | 26.67 |
| Balanced FP32 | 58.80% | 35.10% | 45.14% | 71.88% | 26.56 |
| Balanced Q4 | 57.17% | 41.16% | 45.38% | 64.84% | 26.11 |
| Balanced Q2 | 44.49% | 5.94% | 23.58% | 100.00% | 19.78 |
| Balanced Q1 | 44.49% | **66.06%** | 54.86% | **0.00%** | 26.89 |
| Balanced mixed Q1/Q4/Q4 | 47.56% | 55.87% | 54.62% | **0.00%** | 25.11 |
| Balanced Q2 + 75-step STE repair | 57.88% | 16.00% | 42.54% | 87.50% | 25.89 |

All Q1 "excellent branch recall" and Q2 "excellent STOP recall" figures are **class-specific**, not full-game or artistic wins. Q1 genuinely creates a more branch-happy, STOP-blind personality; Q2 creates a prematurely terminating personality, with STE repair partially restoring class balance. These are potentially valuable mutations, not automatically good policies. The 9-case visual coverage means little without examining original PNGs; no human ratings have been invented. Q1 payload 1,848 B, Q2 2,624 B, Q4 4,176 B, FP32 25,368 B including biases/scales as appropriate. Those numbers exclude NPZ overhead and resident Torch memory.
